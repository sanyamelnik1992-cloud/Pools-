# Запуск бота с нуля — пошагово

Этот файл — для первого запуска на Mac. Всё делается один раз, дальше бот работает сам, а вы смотрите отчёты
в Telegram и при необходимости вмешиваетесь командами.

## Что делает бот, простыми словами

- Держит ваши SUI и USDC в пуле Cetus USDC/SUI (комиссия 0.05%) в узком диапазоне **±4%** вокруг текущей цены и
  получает комиссии с каждого обмена, который проходит через этот диапазон.
- Если цена **3 часа подряд** вне диапазона, бот переставляет позицию вокруг новой цены. Короткие выбросы цены он
  пережидает, чтобы не тратиться на лишние пересборки.
- **Сильный рост** (+15% от минимума за 72 часа) — бот выходит целиком в SUI, чтобы рост не продавал ваши SUI.
  Когда цена откатится на 10% от пика, он возвращается в пул.
- **Сильное падение** (−15% от максимума за 72 часа) — бот выходит целиком в USDC, чтобы падение не съедало капитал.
  Когда цена отскочит на 10% от минимума, он возвращается в пул.
- Перед каждой транзакцией бот симулирует её в сети. После сбоя он сверяется с кошельком и повторяет попытку
  через 2, 6 и 18 минут; после четвёртой ошибки подряд встаёт на паузу и пишет вам.

Эту стратегию выбрали перебором 192 вариантов на истории за год и на сотнях смоделированных путей цены (рост ×2,
боковик, падение ×0.5). Оценка шла относительно «обменять ту же долю SUI на USDC и просто держать». Во всех 8 тестах
результат положительный: в среднем **+32%** капитала за тест, в худшем **+7%**. При утроенных комиссиях обмена и
газа и на новых случайных путях — в среднем +24…29%, в худшем от −3% до +1%.

## Риски — прочитайте до запуска

- **Рынок.** Стратегия проверена на истории и моделях, но будущее может быть другим. Возможен минус.
- **Смарт-контракты.** Cetus взламывали в мае 2025 года (деньги в основном вернули). Это риск любого DeFi.
- **Ошибки бота.** Код проверен тестами и симуляциями в сети, но реальные транзакции он отправит впервые у вас.
- **Поэтому:** отдельный кошелёк, небольшая сумма, первые недели — внимательно смотреть отчёты.

## Шаг 1. Telegram-бот для отчётов и команд (10 минут)

1. В Telegram найдите **@BotFather** → `/newbot` → придумайте имя → получите **токен** (строка вида
   `123456789:AA…`). Сохраните его.
2. Откройте своего нового бота и напишите ему любое сообщение, например «привет».
3. В браузере откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` (вставьте свой токен вместо `<ТОКЕН>`).
   Найдите `"chat":{"id":123456789` — это **id чата**. Сохраните его.

Команды бот принимает только из этого личного чата и только от вас.

## Шаг 2. Отдельный кошелёк для бота (10 минут)

1. В кошельке **Slush** (бывший Sui Wallet) создайте **новый аккаунт** — не используйте основной.
2. Скопируйте его **адрес** (`0x…`).
3. Экспортируйте **приватный ключ** нового аккаунта (настройки аккаунта → экспорт приватного ключа). Это строка
   `suiprivkey1…`. **Никому её не отправляйте**, в том числе мне, и не сохраняйте в файлы проекта.
4. Переведите на новый адрес SUI: сумму для бота (≈ $200, сейчас это примерно 170 SUI) **плюс 2 SUI на газ**.
   USDC отдельно покупать не нужно — бот сам обменяет нужную часть.

## Шаг 3. Программы на Mac (15 минут)

1. Установите **Python 3.12** с python.org (Downloads → macOS → установщик .pkg).
2. Установите **Node.js 22 LTS** с nodejs.org (установщик .pkg).
3. Откройте **Терминал** (Программы → Утилиты → Терминал) и проверьте:
   ```bash
   python3 --version     # должно быть 3.11 или выше
   node --version        # должно быть v22 или выше
   ```

## Шаг 4. Скачать бота (5 минут)

Проще всего — архивом: на GitHub откройте свой репозиторий `Pools-`, переключите ветку на
`claude/lp-pools-analysis`, нажмите **Code → Download ZIP**, распакуйте папку, например, в «Документы».
Или через Терминал (если git настроен):
```bash
cd ~/Documents
git clone https://github.com/sanyamelnik1992-cloud/Pools-.git
cd Pools-
git checkout claude/lp-pools-analysis
```

Дальше все команды — **в папке проекта** (`cd ~/Documents/Pools-` или куда распаковали).

## Шаг 5. Установить зависимости и проверить (5 минут)

```bash
python3 -m pip install requests
cd executor && npm install && cd ..
python3 tests/test_suibot.py
python3 tests/test_live.py
```
Обе проверки должны закончиться строкой «все проверки пройдены».

## Шаг 6. Файл с секретами `.env` и пробный запуск без денег (5 минут)

1. В папке проекта создайте файл `.env` (образец — `.env.example`) ровно с тремя строками:
   ```bash
   export SUI_PRIVATE_KEY="suiprivkey1…"     # ключ НОВОГО кошелька бота из шага 2
   export TG_TOKEN="ваш токен из шага 1"
   export TG_CHAT="ваш id чата из шага 1"
   ```
   Файл в git не попадает (`.gitignore`), бот сам сужает права на него до «только владелец». Никому его не
   отправляйте и не показывайте. Claude Code этот файл не читает (запрет в `.claude/settings.json`).
2. Откройте `suibot.toml` в любом текстовом редакторе (TextEdit → Формат → «Сделать простым текстом»). В разделе
   `[live]` проверьте:
   ```toml
   strategy = "оптимальная ±4%"
   max_capital_usd = 200      # сколько бот возьмёт из кошелька
   dry_run = true             # пока true — ничего не отправляется
   ```
   Адрес вписывать не нужно: в пробном режиме бот берёт адрес из ключа и только симулирует.
3. Проверка всего сразу — ключ, Telegram, баланс кошелька, настройки (ключ на экран не выводится):
   ```bash
   python3 bot.py check
   ```
   Все строки должны быть с ✅, в Telegram придёт «проверка связи». Если есть ❌ — в строке написано, что исправить.
4. Пробный запуск, в Терминале, в папке проекта:
   ```bash
   python3 bot.py live
   ```
   Первая строка — «из …/.env загружены: SUI_PRIVATE_KEY, TG_CHAT, TG_TOKEN». Через несколько секунд должно
   появиться «открыта: виртуальный капитал $200 … симуляция открытия из кошелька … успешно», и это же сообщение
   с пометкой [СИМУЛЯЦИЯ] придёт в Telegram. Значит, всё готово. Остановите: **Ctrl+C**. Пробный режим хранит своё
   состояние отдельно и на реальный запуск не влияет.

## Шаг 7. Боевой запуск

1. В `suibot.toml` поставьте `dry_run = false` и сохраните.
2. В Терминале (в папке проекта):
   ```bash
   caffeinate -i python3 bot.py live
   ```
   Ключ и Telegram бот возьмёт из `.env`. Другой файл (например, на сервере): `python3 bot.py live --env /путь/к/файлу`.
3. Через минуту в Telegram придёт «открыта: кошелёк …, капитал $…, диапазон …». Позицию можно увидеть в Cetus:
   подключите новый кошелёк → Liquidity / My Positions.

**Без файла `.env`** (ключ только в памяти Терминала) — вместо пункта 2:
```bash
export TG_TOKEN="ваш токен из шага 1"
export TG_CHAT="ваш id чата из шага 1"
read -s SUI_PRIVATE_KEY
```
После `read -s` вставьте ключ `suiprivkey1…` и нажмите Enter — на экране ничего не появится, так и должно быть.
```bash
export SUI_PRIVATE_KEY
caffeinate -i python3 bot.py live
```

**На Windows** (PowerShell): файл `.env` работает так же (`python bot.py live`). Без файла:
```powershell
$env:TG_TOKEN = "ваш токен из шага 1"
$env:TG_CHAT = "ваш id чата из шага 1"
$k = Read-Host -AsSecureString "Ключ"
$env:SUI_PRIVATE_KEY = [Runtime.InteropServices.Marshal]::PtrToStringAuto([Runtime.InteropServices.Marshal]::SecureStringToBSTR($k))
python bot.py live
```
Чтобы компьютер не засыпал: Параметры → Система → Питание → «Переводить в спящий режим» — «Никогда».

**Если вы работаете с Claude Code:** бота с реальными деньгами запускаете только вы, в своём окне Терминала.
Claude Code ключ не нужен и `.env` он не читает. Проверить бота он может командой `python3 bot.py status`
(только чтение, ключ не загружает).

## Шаг 8. Каждый день

- Терминал с ботом **не закрывайте**, Mac держите включённым с открытой крышкой (`caffeinate` не даёт ему уснуть).
  Если Mac выключился — позиция остаётся в пуле. После включения повторите команды шага 7: бот сверится с кошельком
  и продолжит с того же места.
- Утром приходит отчёт. В любой момент: `/status` в Telegram или `python3 bot.py status` в другом окне Терминала.
- Команды в Telegram (или `python3 bot.py control <команда>` из другого окна Терминала):
  - `/status` — отчёт;
  - `/pause` — бот ничего не делает, позиция остаётся как есть (выходы на росте и падении тоже не сработают);
  - `/resume` — продолжить;
  - `/sui` — снять позицию и всё в SUI (например, ждёте сильный рост);
  - `/usdc` — снять позицию и всё в USDC (например, ждёте сильное падение);
  - `/close` — снять позицию, монеты оставить как есть;
  - `/events` — последние события;
  - `/alert 1.30` — сообщить, когда SUI дойдёт до $1.30 (`/alert` — список, `/alert off` — снять все);
  - `/strategy` — проверить все стратегии на ценах за 30 и 90 дней (бот сам ничего не меняет, только подсказывает);
  - `/week` — недельный отчёт сейчас: итоги, «тень», график и журнал файлом;
  - `/model` — сверка: сколько заработал реальный бот и сколько показал бы симулятор, по которому выбиралась
    стратегия, за то же время (приходит и каждую неделю после недельного отчёта);
  - `/trend` — тренд SUI на масштабах 50/100/200/365 дней: где цена относительно средних, растут ли они, когда был
    пробой, сколько до максимума и от дна (приходит и каждую неделю; на сделки не влияет), и фаза рынка бота: какая
    сейчас и при какой цене сменится;
  - `/analysis` — все стратегии (боевая и «тень») на всей истории SUI с 2023 и фаза рынка; считается до часа,
    приходит и сам раз в месяц; бот ничего не меняет, только подсказывает;
  - `/settings` — все настройки с пояснениями, какой параметр в `suibot.toml` за что отвечает.

  Под отчётами есть кнопки: 🔄 Обновить, ⏸ Пауза / ▶️ Продолжить, 📜 События. Кнопка «/» рядом с полем ввода —
  список всех команд. В каждом сообщении о действии бота есть строка «🧠 почему» — правило, по которому он так
  сделал, и название настройки в `suibot.toml`, которой это меняется.

  После `/sui`, `/usdc`, `/close` бот на паузе. `/resume` снова откроет позицию вокруг текущей цены.
  Команды, отправленные, пока бот был выключен, не выполняются — после запуска отправьте нужную команду заново.
  Если бот сам вышел в SUI или USDC по правилу, `/resume` после паузы ничего не ломает: он вернётся в пул только
  после отката или отскока на 10%. В фазе роста `/resume` пул не открывает — бот держит всё в SUI до конца роста.

| «🧪 проверка стратегий» (раз в неделю) | Если есть 💡-подсказка — обсудите со мной, прежде чем менять стратегию. |

## Шаг 9. Раз в неделю

Пришлите мне `/status` и файл `data/private/bot/live/events.csv`. По ним будем улучшать стратегию. Через 4–8 недель
решим, увеличивать ли сумму. Чтобы увеличить:
1. Переведите SUI на кошелёк бота.
2. Сделайте `/close` и Ctrl+C.
3. Поднимите `max_capital_usd` в `suibot.toml` и удалите файл `data/private/bot/live/state_real.json`.
4. Запустите заново (шаг 7): бот начнёт с нового лимита, взяв монеты из кошелька.

## Править бота с телефона

Бот работает на сервере, код — на GitHub (ветка `claude/lp-pools-analysis`). Можно менять его прямо на GitHub или
через Claude в браузере в этом же репозитории. Через 15 минут в Telegram придёт «🔔 На GitHub новые изменения».
Напишите Claude Code «проверь гит»: он заберёт изменения, проверит их и тесты и только потом выложит на сервер.
До проверки бот работает на прежней версии — непроверенный код с реальными деньгами сам не запускается.

## Обновить бота до новой версии

1. `/close` (или `/sui`) — бот снимет позицию, всё останется в кошельке. Затем Ctrl+C.
2. Скачайте новую версию (шаг 4) и выполните шаг 5.
3. Удалите файл `data/private/bot/live/state_real.json` в новой папке, если он там есть. Перенесите туда
   `events.csv` из старой папки, если хотите сохранить журнал. Перенесите и файл `.env`.
4. Запустите (шаг 7). Бот начнёт с того, что лежит в кошельке.

## Как остановить совсем и забрать деньги

1. `/close` (или `/sui`, если хотите всё в SUI) — бот снимет позицию и встанет на паузу.
2. Ctrl+C в Терминале.
3. В Slush переведите SUI, USDC и награды (CETUS) с кошелька бота на основной.

## Правила безопасности

- Ключ — только в файле `.env` на компьютере (или сервере) бота или в Терминале через `read -s`. Больше никуда
  его не записывайте и никому не отправляйте, в том числе Claude.
- Отдельный кошелёк, на нём только деньги бота.
- Не меняйте позицию бота вручную в Cetus, пока бот работает. Сначала `/close` или `/pause`.
- Не увеличивайте сумму, пока бот не проработал хотя бы несколько недель без ошибок.
